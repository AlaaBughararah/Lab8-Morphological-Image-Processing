# Lab 8 — Morphological Image Processing

This lab applies morphological operations to a binary image containing filled and hollow shapes with random white noise.

## Tasks
1. Apply erosion, dilation, opening, and closing using a 5×5 square kernel.
2. Repeat the operations using a circular kernel with radius 5 (11×11).
3. Compare how kernel shape and size affect the results.

## Tools
- Python
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## How to Run
Open the notebook in Jupyter Notebook or JupyterLab and run all cells from top to bottom.
